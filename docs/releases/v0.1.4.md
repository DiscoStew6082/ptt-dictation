# v0.1.4 — Faster local Qwen recognition

Adds optional native CUDA inference for Qwen3-ASR 1.7B BF16 while retaining
Parakeet live preview, normal hotkeys, cancellation, and text insertion.

- On the tested RTX 3060, installed recognition time fell from 1.68 to 0.39
  seconds for a 5.9-second recording, and from 5.50 to 1.32 seconds for a
  29.4-second recording. The 30-case comparison showed no additional word
  errors. These measurements apply to the separately configured native backend.
- Recordings over five minutes retain the original whole-recording fallback.
  Cancellation, worker cleanup, recovery, and switching back to native inference
  were verified with real models.
- The existing CUDA Transformers worker also receives faster RMS normalization;
  its CPU behavior and dependency versions are unchanged.
- Includes the installation, update, and regression-test maintenance since
  v0.1.3. Updates preserve the selected permanent installation path and settings.

The Windows x64 ZIP includes both worker adapters. Native CUDA runtime/model
assets require separate verified registration; they are not bundled or
automatically enabled by this app update. The registration script and pinned
asset manifest are in this release's **Source code (zip)**. Existing CPU
installations continue to work. See [native setup and rollback](https://github.com/DiscoStew6082/ptt-dictation/blob/v0.1.4/docs/qwen-final-transcription.md#optional-native-cuda-inference)
and the [measurements and validation details](https://github.com/DiscoStew6082/ptt-dictation/blob/v0.1.4/docs/research/qwen-latency-2026-10-26.md).

Download `PttDictation-win-x64.zip`, its `.sha256`, and `Install-PttDictation.ps1`.
The release also includes a CycloneDX SBOM and GitHub build-provenance
attestation. The app remains unsigned; see
[SECURITY.md](https://github.com/DiscoStew6082/ptt-dictation/blob/v0.1.4/SECURITY.md)
for verification and privacy details.
