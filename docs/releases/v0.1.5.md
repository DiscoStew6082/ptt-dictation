# v0.1.5 — Automatic native Qwen setup

**Download Qwen** now installs and enables the faster native CUDA engine on
supported NVIDIA hardware. Existing Qwen users can choose **Check Qwen setup**
after updating. No source checkout, separate Python installation or native
registration script is required. Select Qwen for final recognition and save
Settings; installation preserves the selected engine.

- Setup checks hardware, downloads pinned assets, verifies every native file,
  and loads the real model before activating it. Unsupported hardware retains
  the standard backend. Failed or cancelled native setup reports its fallback
  and can be retried without losing completed downloads.
- Activation waits for active recognition and serializes the backend change
  with desktop, phone and preload requests. It cleans up its owned workers.
- Downloads retry bounded transient server failures while respecting
  `Retry-After`. Private runtime paths are shorter to avoid deep Windows wheel
  extraction failures.
- Updated setup, privacy, contributor and project-status documentation;
  historical release instructions remain labeled by their original version.

A real installation from empty app data on an RTX 3060 passed initial setup and
a second reuse check. Its native backend was **3.8× faster overall** than the
recorded original CUDA engine on the same 30-case corpus, with no additional word
errors or unstable repeated results. A 5.9-second recording took 0.40 seconds;
a 29.4-second recording took 1.43 seconds. See the
[fresh-install validation](https://github.com/DiscoStew6082/ptt-dictation/blob/v0.1.5/docs/research/qwen-automatic-setup-2026-10-27.md)
for scope and limitations.

Automatic native setup requires Windows x64, CUDA device 0 with at least 8 GiB
VRAM and compute capability 8.0+, an NVIDIA driver exposing CUDA 12.4+, and no
`CUDA_VISIBLE_DEVICES` override. Model/runtime assets are separate downloads:
approximately 4.1 GB for the HF model, plus Python/packages and another 5.37 GB
for native assets. Recordings over five minutes retain the original whole-recording
fallback, which runs on CPU with managed setup and does not receive this speedup.
See [Qwen setup](https://github.com/DiscoStew6082/ptt-dictation/blob/v0.1.5/docs/qwen-final-transcription.md).

Download `PttDictation-win-x64.zip`, its `.sha256`, and
`Install-PttDictation.ps1`. The release includes a CycloneDX SBOM and GitHub
build-provenance attestation. The app remains unsigned; see
[SECURITY.md](https://github.com/DiscoStew6082/ptt-dictation/blob/v0.1.5/SECURITY.md).
